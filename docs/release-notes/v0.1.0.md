First release: a command-line tool that converts **TrackMania Nations/United Forever** Stadium tracks from
[TMNF-X](https://tmnf.exchange) into **Assetto Corsa** tracks and installs them for Content Manager.

## Requirements

- Windows 10/11 (x64)
- Assetto Corsa with [Custom Shaders Patch](https://acstuff.club/patch/) (converted tracks need CSP)
- TrackMania Nations Forever (free on Steam). Block meshes and textures are read from your own install.

`tm2ac.exe` is a single self-contained file, so you don't need to install .NET.

## Usage

```powershell
tm2ac doctor                              # finds AC, CSP and TMNF
tm2ac search tmnf --tag Tech --limit 10   # browse TMNF-X
tm2ac convert tmnf 414041                 # convert and install into AC's content/tracks
```

Useful options: `--scale 1.5` (bigger track for slower cars), `--replay <id or file>`, `--pitboxes <n>`, `--out <dir>`,
`--zip <file>`. See the [README](https://github.com/costbubbles/TM-track-exporter#readme).

## What you get

- Original block meshes and textures, with collision surfaces (road, kerb, dirt, grass, ice); steep faces become walls
- Timing: start/finish and sectors on circuits, start and finish gates on A-to-B tracks
- Every session (race, practice, hotlap) starts at the start line
- Minimap, outline and preview for Content Manager, plus `conversion-report.json` with any warnings
- The replay used for layout and sectors is a gold-medal-level run from TMX (world records often skip parts of the route)
- A `JUMPS` warning when the route jumps over gaps, with the speed the hardest jump needs

## Known limitations

- No AI line: very few Trackmania maps can be driven conventionally, so AI isn't supported.
- Tracks are converted as they are. Loops, wall rides and some jumps can't be driven with AC physics.
- Boosters don't boost, and special surfaces are approximated.
- Hitting thin walls can occasionally drop a car through the map, as with many AC track mods.
- Steep steps such as raised start pads can clip tyres, especially on mod cars with minimal hitboxes.
- Only TMNF/TMUF Stadium for now. A desktop app (v0.2) and Trackmania 2020 (v0.3) are planned.
